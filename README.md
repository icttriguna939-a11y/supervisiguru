# Supervisi Guru — SMA Triguna 1956 Jakarta

Aplikasi penilaian supervisi tenaga pendidik berbasis **Pembelajaran Mendalam** (Kurikulum Merdeka).

- **Frontend:** situs statis ini (GitHub Pages) — HTML/CSS/JS murni, tanpa framework.
- **Backend:** Google Apps Script sebagai REST API (`Kode.gs`, tidak disimpan di repo ini).
- **Konfigurasi:** isi `GAS_URL` di `js/config.js` dengan URL `/exec` Web App.

Fitur: jadwal supervisi, formulir observasi dengan simpan otomatis, mesin skor berbobot, rekomendasi AI yang wajib ditinjau, pengesahan, refleksi & tindak lanjut guru, laporan PDF A4, dasbor analitik, log audit, mode gelap, tampilan ponsel.

Lihat **PANDUAN-INSTALASI.md** untuk langkah lengkap.
